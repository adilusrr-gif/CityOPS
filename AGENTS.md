# Project instructions

- Maintain this project in `https://github.com/adilusrr-gif/webApp.git` once authorized access is available.
- The user requests that every completed change be committed and pushed. Group one coherent change per commit and push after validation. Never claim a push succeeded unless Git confirms it.
- If access is unavailable, preserve the work as a downloadable archive and report the limitation. Do not bypass workspace administrative restrictions.
- Never commit `.env`, credentials, session tokens, `data/*.sqlite`, player location history, or production user data.
- Keep code understandable and the Russian interface functional on mobile screens.
- Do not claim the organization directory is complete or that browser GPS proves physical presence.
- Preserve role checks, moderation and idempotent rewards. Run `npm test` for server changes.
- OSM-derived datasets must retain attribution and ODbL notices. Do not copy proprietary map catalogs.
