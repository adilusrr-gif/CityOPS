## Интеграция

Версия приложения 0.8.0, Android/iOS build 8. Общий UI пересобран и синхронизирован в обе native-платформы. PWA cache имеет новую версию и включает модуль срока жизни координат. Структуры SQLite 5 / PostgreSQL 6 и выпущенные SQL-миграции сохранены; DDL обновления не требуется. Рекламные management endpoints теперь возвращают страницы, поэтому внешние клиенты должны использовать `next_cursor`. Обновлённый UI скрывает геопозиции от старого API без TTL; это безопасное поведение при смешанных версиях.

Проверки не суммируются с точечными повторными прогонами. Актуальные итоговые числа, браузерные свидетельства и сборка: [VALIDATION.md](VALIDATION.md). Предыдущий отчёт: [ULTRACODE-REVIEW-V7.md](ULTRACODE-REVIEW-V7.md).

## Оставшиеся ограничения и обязательная приёмка

- Startup encryption sample проверяет не более одного аккаунта с MFA-state, одного сообщения и одного cached reply. Это обнаружение типичной подмены ключа, а не проверка всей истории. Пустая база не доказывает согласованность ключей между репликами; полный `--database` gate обязателен после настройки и перед выпуском. Сохраняйте исходные ключи отдельно от резервной копии.
- Структурная проверка JPEG при операторском импорте не доказывает отсутствие всех скрытых данных. Специально подделанный backup с лишними байтами внутри entropy scan до EOI может пройти проверку и декодер. Обычный upload декодирует и перекодирует файл. Импорт допускается только из доверенного backup; полная нормализация импортируемых изображений с пересчётом hash/ledger остаётся отдельной работой. Нельзя считать v0.7 проверку универсальным удалением стеганографии.
- PGlite выполняет PostgreSQL SQL, но сериализует транзакции. Три native-only проверки обязательны в CI с настоящим PostgreSQL; локальный прогон не подтверждает contention, репликацию или failover.
- Не выполнены production TLS/DNS/IdP, кластерный rollout/restore/PITR, нагрузка площадки, живые AI/эквайринг, подписанные APK/AAB/IPA и проверка телефонов. Пример HTTPS origin необходимо заменить и пересобрать приложение. Startup HMAC по истории остаётся линейным; точные totals и ранжирование требуют измерений на целевых данных.
- Каталог OSM не гарантирует полноту, GPS не доказывает присутствие, фотоголоса не защищают от всех видов накрутки. Горный маршрут остаётся draft до полевой проверки. SQL-хранилище фото и ручное подтверждение платежей остаются границами пилота.
