# Проверка версии 0.4.0

Проверено 23 сентября 2026: Linux x64, Node.js 24.19.0, Chromium 134 / Playwright 1.51.1. Тестовые аккаунты, рабочие базы, секреты и зависимости node_modules в архив не включаются.

## Автоматические проверки

| Набор | Пройдено | Ошибки | Пропущено |
| --- | ---: | ---: | ---: |
| `npm test` — SQLite, безопасность, питомец, провайдер, billing, mobile transport, HTTP | 111 | 0 | 0 |
| `npm run test:enterprise` — PostgreSQL SQL, миграции, API, OIDC, две HTTP-реплики | 66 | 0 | 1 |
| `node --test deploy/*.test.mjs` | 4 | 0 | 0 |
| **Всего** | **181** | **0** | **1** |

Единственный пропуск — реальный конкурентный `SKIP LOCKED` на двух соединениях native PostgreSQL. Локальные enterprise-тесты используют настоящий PostgreSQL SQL engine через PGlite/WASM, который сериализует транзакции. Это не доказательство native concurrency, репликации или failover. В CI задан обязательный `PG_TEST_REQUIRED=true`; CI здесь не запускался.

Внешний ИИ подменён контролируемым HTTP-адаптером фиксированных официальных endpoint. Проверены реальные маршруты приложения и шифрование; результаты не подтверждают качество или доступность живой модели. Платёжные подтверждения сделаны только на изолированных тестовых данных, денег не списывали.

## Что проверено в v0.4

- Аддитивные схемы SQLite 3 / PostgreSQL 4, checksum, повторные миграции, сохранение старых пользователей/сессий/игры. Перенос SQLite-схем 2 и 3 с проверкой HMAC, ключей и AAD зашифрованной переписки.
- Общий generator store: SQLite-транзакция не уступает event loop; PostgreSQL использует закреплённое соединение. Ошибки SQL/аудита откатывают изменения; действующая сессия проверяется после получения блокировок.
- Рост питомца: уникальные награды ухода и подтверждённых квестов, отсутствие повторного XP и деградации за паузу. Дополнительные цвета требуют активного Plus.
- AI: явное согласие 18+, bounded context, `store:false`, модерация входа/выхода и отказ при её ошибке, отсутствие аккаунта/GPS/email в служебных полях payload, ограничение времени и размера ответа.
- Идемпотентный чат, общая и личная квоты, отсутствие сетевого вызова внутри транзакции, учёт неопределённой ошибки провайдера. Сценарный чат ограничен 100 сохраняемыми обращениями/сутки; статические упражнения и помощь не используют квоту.
- AES-GCM/AAD привязывает текст к владельцу и записи. Удаление, отзыв согласия и сессии во время генерации не возвращают историю. Очистка истёкших данных ограничена пакетами.
- Серверная цена KZT, отдельные права покупателя/администратора, обязательная MFA финансовых действий, уникальный payment reference, идемпотентные подтверждение/возврат, фиксированный срок, отзыв доступа. Ошибка аудита откатывает платёжные изменения.
- Реклама: проверка владения, одобрения места и доступности публичного квеста, тарифных слотов, модерации и версии. Истёкшая/отозванная подписка исключает объявления из публичного ответа.
- Native: запрет web checkout, bearer только в памяти, поздний 401 или logout старого аккаунта не сбрасывает новую сессию. Проверены прежние PKCE, CORS и игровые сценарии.

## Браузер и сборка

16 сценариев нового интерфейса прошли на 1440, 390 и 320 px: выбор питомца, забота, чат, безопасное отображение пользовательского/модельного текста, удаление и поздние ответы, тариф, подтверждение внешней оплаты, рекламный кабинет/модерация/возврат, ограничение native checkout, согласие на ИИ, свободные упражнения и безопасные повторы после 503. Отчёт: [v4-browser-results.json](v4-browser-results.json).

Дополнительно прошли 5 сценариев: PWA install/cache/offline/reconnect и исполнение собранного Capacitor bundle в Chromium web fallback: переключение Астаны, регистрация, питомец и сохранение XP на 320 px. Отчёт финальной сборки: [../mobile/validation-v4-pwa-bundle.json](../mobile/validation-v4-pwa-bundle.json). Кеш содержит только статические ресурсы; API, разговоры, координаты и награды не кешируются.

Реальные OpenFreeMap-ресурсы для основного UI передавались через Node HTTP-клиент из-за сетевых особенностей браузерной среды. Native-проверки в браузере используют симуляцию мостика или web fallback; Android Emulator, iOS Simulator и реальные устройства не проверялись.

`CITYQUEST_API_ORIGIN=https://cityquest.example npm --prefix mobile run sync` собирает общий интерфейс и синхронизирует Android/iOS assets. Android/iOS version 0.4.0, build 4. Включённый HTTPS origin — зарезервированный пример, его нужно заменить своей сборкой. APK/AAB/IPA не собраны и не опубликованы: требуемых SDK/JDK 21/Xcode и подписи владельца здесь нет.

## Production-конфигурация

Отрендерены 9 Kustomize-каталогов, проверены 17/17 ресурсов Kubernetes/CloudNativePG/Barman; три env-примера приняты фактическими конфигураторами функций. ExternalSecret/ServiceMonitor отрендерены, admission операторов не испытан. Подробнее: [DEPLOYMENT-VALIDATION.json](DEPLOYMENT-VALIDATION.json).

Синтаксис JS проверен. `npm audit --omit=dev` не сообщил известных уязвимостей на дату проверки; это не независимый аудит безопасности.

## Границы поставки

Не запускались живой OpenAI, эквайринг/IAP, реальные денежные возвраты, Docker runtime, Kubernetes-кластер, production TLS/DNS/IdP, native PostgreSQL contention/failover, WAL/S3/PITR или нагрузка на целевой площадке. Не подтверждены медицинская эффективность, отказоустойчивость и магазинное одобрение. Мониторинг, резервирование и модерация требуют работы оператора.

Обновление PostgreSQL v0.3→v0.4 требует окна обслуживания, сохранения ключей, миграции и обновления grants; смешанный rollout не поддерживается. Инструкции: [PRODUCTION-HA.md](PRODUCTION-HA.md), [AI-PET.md](AI-PET.md), [MONETIZATION.md](MONETIZATION.md).

Результаты предыдущей версии сохранены в [VALIDATION-V3.md](VALIDATION-V3.md); старые browser/load отчёты не выданы за новый прогон v0.4. Доступ к GitHub был заблокирован административной политикой рабочей среды, поэтому push не выполнен; поставка сохранена архивом.
